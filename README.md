# 实况照片拼接 (Live Photo Stitch)

一款专为安卓手机（特别是小米手机）设计的实况照片拼接应用。

## ✨ 功能特点

### 🎨 智能拼接
- **固定输出比例**：由模板决定，确保输出尺寸一致
- **紧凑布局**：照片边缘紧贴，无间距，自动裁剪填充
- **6 种模板**：
  - 横向三格 (16:9)
  - 纵向三格 (9:16)
  - 中间大两边小 (16:9)
  - 左大右小 (16:9)
  - 右大左小 (16:9)
  - 四宫格 (4:3)

### ✨ AI 人物突出
- **可选功能**：对任意一张照片启用
- **自动识别**：使用 ML Kit 人像分割
- **超出边框**：人物可放大并超出格子边界，覆盖到相邻照片
- **背景不变**：保持原有背景，不超过原有图片大小
- **参数调节**：
  - 放大倍数 (100%-300%)
  - 人物位置（水平/垂直）

### 🎬 实况照片
- **输出完整实况照片**：静态图 + 短视频
- **视频内容**：包含所有照片的拼接画面
- **保存到相册**：自动保存到系统相册

## 📱 使用步骤

1. **选择照片**
   - 点击"开始创作"
   - 选择 3 张照片（支持实况照片和普通照片）
   - 点击"下一步"

2. **选择模板**
   - 浏览 6 种模板布局
   - 选择喜欢的模板
   - 点击"下一步"

3. **编辑照片**（可选）
   - 点击预览中的照片进行选择
   - 选择底部工具：
     - **缩放**：调整照片大小
     - **AI突出**：启用人物抠图+放大
     - **滤镜**：应用滤镜效果
     - **旋转**：旋转照片
   - 点击"预览"

4. **预览与保存**
   - 查看拼接效果
   - 确认包含动态效果（实况照片）
   - 点击"保存"保存到相册

## 🔧 安装说明

1. 下载 APK 文件
2. 在手机上允许"安装未知来源应用"
3. 安装应用
4. 首次使用请授予存储权限

## 🛠️ 技术栈

- **Kotlin** + **Jetpack Compose**
- **Material Design 3**
- **ML Kit** 人像分割
- **MediaCodec/MediaMuxer** 视频处理
- **Coil** 图片加载
- **Hilt** 依赖注入

## 📋 系统要求

- Android 8.0 (API 26) 或更高版本
- 建议 Android 10+ 以获得最佳体验
- 小米/Redmi/POCO 手机均可使用

## ⚠️ 注意事项

- 处理过程需要一定时间，请耐心等待
- AI 人物突出功能需要联网下载模型
- 输出照片分辨率为 1080px 宽度
- 视频时长取决于原照片的视频时长
